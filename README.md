# InLeagle — Indian Banking Law Assistant

RAG-powered assistant for Indian banking law.

Built with:
- InLegal-Sbert embeddings (bhavyagiri/InLegal-Sbert)
- Qdrant Cloud vector database
- Groq LLaMA 3.1 for generation
- FastAPI + HTML frontend

## Data Sources
- Acts: SARFAESI, IBC, NI Act, PMLA, Banking Regulation Act, CIC Act
- RBI: Ombudsman Scheme, Digital Lending Guidelines, Fair Practices Code
- Cases: 8 landmark Supreme Court judgments
